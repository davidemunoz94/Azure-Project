# Microsoft Azure architecture icons

These SVGs are unmodified files selected from Microsoft's Azure Public Service Icons V24 package, downloaded November 3, 2026. The architecture diagram embeds these files without cropping, rotation or distortion. Logical Pod, laptop and internet symbols are custom diagram shapes.

Source and terms: [Microsoft Azure architecture icons](https://learn.microsoft.com/en-us/azure/architecture/icons/). Microsoft permits these icons in architecture diagrams, training materials and documentation, and reserves other rights. Product names appear beside the icons. Archive paths and original-file hashes are recorded in SOURCE.json.
