# Microsoft Azure architecture icons

These six SVGs are unmodified selections from Microsoft's Azure Public Service Icons V24 package, reused from lab 1. Original archive paths/hashes and source URL are in SOURCE.json. [Source and usage terms](https://learn.microsoft.com/en-us/azure/architecture/icons/): Microsoft permits architecture diagrams, training material and documentation and reserves other rights. Product names accompany icons; aspect ratios and artwork are retained. Pod/client/configuration shapes are custom, not Azure services.
